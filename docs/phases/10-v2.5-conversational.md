---

## Amaç

Kullanıcıya doğal bir sohbet yüzeyi: mesaj → investigation request → engine → evidence/review → kısa yanıt. LLM tabloyu analiz etmez.

---

## Mimari

```text
User message
  → POST /chats/{id}/messages
  → classify (metin; SQL/Python değil)
       ├─ investigate → run_investigation (mevcut graf)
       └─ show_steps / show_evidence / focus_existing → son run state
  → assistant: text + claim_ids + evidence_ids + status
```

Follow-up (“West'i daha detaylı incele”) yeni unrelated run açmaz; son `run_id` evidence’sini özetler.

---

## API

| | |
| --- | --- |
| `POST /chats` | `{ dataset_id }` |
| `GET /chats/{id}` | history |
| `POST /chats/{id}/messages` | `{ text }` |
| `GET /chat` | sohbet HTML |

`POST /datasets/{id}/analyze` ve `/` konsolu durur.
