## Eval

Katalog: `evals/adversarial.json`  
Koşucu: `analysis/eval/adversarial.py`

Her satır:

- `category`
- `expected_behavior`
- `actual_behavior` (decision, primary_driver, stop_reason, claim/review özeti)
- `pass` / `failure_reason`
- fail ise `failure_class`: **A** gerçek bug, **B** mevcut capability sınırı, **C** V2.4 Adaptive Research, **D** yeni tool/capability

`must_pass: true` olanlar (nedensel dil kilidi, teslimat abstain) V1 regresyonudur; `python -m analysis.eval` ve pytest bunları kilitler.

`must_pass: false` olanlar **raporlanır**, V1 `pass` kapısını düşürmez.

```bash
uv run python -m analysis.eval.adversarial
uv run pytest tests/test_adversarial.py
```
