## Amaç

Araştırmayı tek seferlik hipotez listesi olmaktan çıkarıp, evidence yeterliliğine göre **kapalı şablon** içinde bir sonraki adımı seçmek.

---

## Graf (state machine)

```text
inspect → profile → detect_capabilities → intersect
  ├─ skip (capability boş) → validate_claims → review_claims → report
  └─ rank_hypotheses → experiment_loop → score → assess_evidence
         ├─ sufficient → stop → validate_claims → review_claims → report
         └─ insufficient → next_research → assess_evidence → …
```

`next_research` yalnızca kayıtlı `test_hypothesis` / `CLOSED_TEMPLATES` çalıştırır. Yeni operator yok.

---

## Yeterlilik (neden yeni adım)

| Kind | Ne zaman |
| --- | --- |
| `multiple_plausible_drivers` | ≥2 hücre `share_of_change ≥ 0.5` |
| `needs_decomposition` | Unique driver var, `volume_vs_value` henüz yok |
| `unanswered_question` | Abstain, gürültü değil, ranked hipotez kaldı |
| `budget` | `max_experiments` / `max_adaptive_steps` / süre doldu |

Unique `primary_driver` (V1 clear_driver) **yeterli** sayılır → `next_research` yok. Golden bozulmaz.

Her follow-up `research_steps[]` içinde `reason`, `kind`, `template_id`, `hypothesis_id` taşır (UI/report için state).

---

## Budget

Mevcut `Budget` + `max_adaptive_steps` (varsayılan 4). Doluysa **abstain / insufficient**, uydurma driver yok.
